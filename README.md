# Welcome to the Meal Analyzer
This web application lets users upload images of meals from their desktop and receive useful information about the meal shown in the image. The application analyzes the image and provides details such as the meal's name, description, and calorie count.

# Features
**Image Upload** - Upload an image of a meal directly from your computer<br>
**Meal Recognition** - Analyze the image to identify the meal or food shown<br>
**Meal Description** - Receive a description of the identified mean<br>
**Calorie Estimation** - Get an estimated calorie count based on the analyzed meal<br>
**Simple Interface** - Quickly upload an image and view the results
