# Welcome to the Meal Analyzer
This web application lets users upload images of meals from their desktop and receive useful information about the meal shown in the image. The application analyzes the image and provides details such as the meal's name, description, and calorie count.

# Features
**Image Upload** - Upload an image of a meal directly from your computer<br>
**Meal Recognition** - Analyze the image to identify the meal or food shown<br>
**Meal Description** - Receive a description of the identified mean<br>
**Calorie Estimation** - Get an estimated calorie count based on the analyzed meal<br>
**Simple Interface** - Quickly upload an image and view the results

# How to Set Up
Getting started with this software is fairly straightforward. Follow the steps in order:
1. Clone this repository onto your local machine.
2. Ensure you have Python 3.12.7 installed.
3. Create a Python virtual environment and activate it. See how: [Python Documentation](https://docs.python.org/3/library/venv.html)
4. Install backend dependencies from the requirements.txt file.
5. Create a .env file to hold environment variables. Make sure it is located inside your project's root folder.
6. Create a field in the file called "OPENAI_API_KEY" and request the key from me. Paste the key into the field.
7. Run the meal analyzer, which can be opened in your browser.
